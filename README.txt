# M3D Engineering website

## Publish for free
1. Open `index.html` in a browser to test it.
2. Replace `21600000000` in the JavaScript with your WhatsApp number.
3. Replace the six portfolio placeholders with your own photos.
4. Upload the folder to GitHub Pages or Cloudflare Pages.

No backend is required: the quote form opens WhatsApp with the customer's request.

## Customize
Search `M3D Engineering` in index.html to change the brand name.
Search `YOUR PROJECT PHOTO` to replace portfolio placeholders.
